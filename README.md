# Barbie Wordle

*Barbie Wordle* is a final project for the Operating Systems course, written in Java 
with JavaFX in 2023 as part of a bachelor's studies at the University of Tartu. It has been vibe-coded into JavaScript so the game can be played in the browser in English and Estonian.
